# shenle-api-cli 0.1.0 版本说明

## 功能

第一版，提供三个核心子命令：

| 命令 | 功能 |
|------|------|
| `send` | 读请求 JSON（文件 / stdin）→ 发 HTTP → 把 `{request, response, meta}` 落盘到 `%TEMP%/shenle-api-results/` |
| `extract` | 从结果文件抽变量：`--field "$.data.token"` 走 JSONPath；非 `$` 开头自动走 AI 自然语言 |
| `assert` | 自然语言断言：`assert <result> "data.msg 等于 SUCCESS"` → AI 判断 → exit 0/1 |

## 运行逻辑

1. **CLI 入口**：`shenle-api-cli = shenle_api_cli.cli:main`
2. **send 流程**：
   - 读请求 JSON（`req.json` 位置参数 / `--input` / stdin 三选一）
   - `request_builder.build_requests_args()` 把 `headers` / `urlParams` / `bodyParams` 列表转成 requests 参数
   - `http_client.send_request()` 发请求 → 探测编码 → 解析 JSON（失败就保留原始 text）
   - `result_store.save_result()` 落盘到 `%TEMP%/shenle-api-results/<YYYYMMDD-HHmmss>-<uuid8>.json`
3. **extract 流程**：
   - 读 result 文件 → 拿 `response.body_json`
   - field 以 `$` 开头 → `jsonpath.eval_path()` 本地查
   - 否则 → `ai.ask_text()` 调 chat/completions（强制 `response_format: json_object`）
4. **assert 流程**：
   - 读 result 文件 → 拿 `response.body_text`
   - `ai.ask_text()` 让 AI 判断 → 返回 `{passed, reason}` → exit 0/1

## 与上一版的区别

**0.1.0 是第一版**，没有「上一版」可对比。规划中的 v0.2 路线：

- `batch` 子命令（一次 send + extract 多个 request，省 AI 多次调用）
- binary response 支持（base64 编码 + 落盘）
- multipart/form-data 文件上传
- HAR 文件 → req.json 转换器（与 shenle-api-record raw 互通）
- runner.py `_BASE_SYSTEM_PROMPT` 把 curl 默认改成 shenle-api-cli（用户确认后再做）

## 数据契约速查

**请求**：
```json
{
  "url": "...",
  "method": "POST",
  "headers": [{"name": "...", "value": "..."}],
  "urlParams": [{"name": "...", "value": "..."}],
  "bodyParams": [{"name": "...", "value": "..."}]
}
```

**结果**：
```json
{
  "request": { ...原样回写... },
  "response": {
    "url": "...", "status": 200, "headers": {...},
    "body_text": "...", "body_json": {...} | null,
    "elapsed_ms": 234, "called_at": "2026-09-24T..."
  },
  "meta": {"tool_version": "0.1.0", "cli_cmd": "...", "size_bytes": 1234, "body_truncated": false}
}
```

## 已知限制

1. 不支持 multipart 文件上传（v0.2）
2. 不支持二进制 response（>10MB 自动截断，meta.body_truncated=true）
3. JSONPath 是极简实现（点路径 + 数组下标），不支持 `$..` / `$.*` / filter 表达式；需要时用自然语言兜底
4. `--no-fail-on-status` 默认关，4xx/5xx 默认抛 [FAIL]
5. 第一版未修改 `shenle-ai-test-runner` 的 `_BASE_SYSTEM_PROMPT`；用户必须显式传 `--system-prompt` + `--skills-dir` 引入

## 端到端验证（已通过）

```bash
# 1. 安装
.venv/Scripts/python.exe -m pip install -e apps/shenle-api-cli
shenle-api-cli --version

# 2. send
cat > /tmp/req.json << 'EOF'
{"url": "https://httpbin.org/get", "method": "GET",
 "urlParams": [{"name": "中文", "value": "测试"}]}
EOF
shenle-api-cli send /tmp/req.json

# 3. extract JSONPath
RESULT=$(ls -t /c/Users/95431/AppData/Local/Temp/shenle-api-results/*.json | head -1)
shenle-api-cli extract "$RESULT" --field '$.args.中文'

# 4. 自然语言（需 .env 配 API_AUTOMATION_AI_*）
shenle-api-cli extract "$RESULT" --field 'foo 参数的值'
```
