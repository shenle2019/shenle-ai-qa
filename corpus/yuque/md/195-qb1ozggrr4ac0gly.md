# 概述

## 什么是 Python

- Python 是一种广泛使用的高级编程语言，以其代码的可读性和简洁性而著称。它由 Guido van Rossum 在 1980 年代末期创建，并在 1991 年首次发布。Python 的设计哲学强调代码的可读性，以及允许使用缩进来表达语句块。
- Python 支持多种编程范式，包括面向对象、命令式、函数式编程等风格。它的语法简单直接，使得初学者能够较快地掌握并开始编写程序。Python 拥有强大的标准库，并且有一个活跃的社区，开发了大量的第三方模块，几乎涵盖了所有可以想象的应用领域，如Web开发、科学计算、图形处理、数据库管理、网络爬虫、自动化测试等。
- Python 有两个主要版本：Python 2 和 Python 3。Python 2 已经停止维护，官方推荐使用 Python 3。Python 被广泛应用于教育、科研、Web 开发、数据处理、机器学习等领域，是当今最流行的编程语言之一。

官方文档：<http://python.p2hp.com/doc/index.html>

## Python 解释器

计算机的 CPU 是不认 Python 代码的，只支持 0 和 1，需要通过解释器去将 python 的代码翻译成计算机认识的内容

Python 解释器是用来执行 Python 编程语言编写的代码的程序。Python 解释器读取 Python 源代码，分析它，并将其转换成计算机可以直接执行的指令。以下是几种常见的 Python 解释器：

1. **CPython**：这是最常见的 Python 解释器，通常所说的 Python 就是指 CPython。它是用 C 语言编写的，并且是开源的。当你从官方网站下载 Python 时，你实际上是在获取 CPython。
2. **Jython**：这是一个让 Python 代码运行在 Java 平台上的解释器。它将 Python 字节码转换成 Java 字节码。
3. **IronPython**：这个解释器允许 Python 代码在微软的 .NET 框架上运行。它把 Python 字节码转换成微软中间语言（MSIL）。
4. **PyPy**：这是一个替代性的 Python 解释器，它使用了即时编译技术来加速 Python 代码的执行速度。PyPy 兼容 CPython 的源代码并且支持 Python 2 和 Python 3。
5. **Stackless Python**：这是一个特殊的 Python 版本，它对协程的支持更好，使得它可以更好地处理大量的并发任务。

为了执行 Python 脚本，你需要安装一个 Python 解释器。通常情况下，安装 Python 语言本身就会包含一个默认的解释器（通常是 CPython）。此外，Python 解释器也可以作为命令行工具使用，允许你直接在终端或命令提示符中输入 Python 代码并立即看到结果。

## 变量

在 Python 中，变量是用来**存储数据值的标识符**。变量代表的值可以改变，Python 的变量不需要**显式**声明类型，而是根据赋给它的值来确定其类型

- 标识符：在编程语言中，标识符（identifier）是用来命名变量、函数、类、模块等程序元素的名称。标识符遵循命名规则和约定。

### 命名规则

变量名是有命名规则的，不遵守就报错

- **字母或下划线开头**：变量名必须以字母（a-z 或 A-Z）或下划线（\_）开头。

- ​

- **只能包含字母、数字和下划线**：变量名可以包含字母、数字和下划线，但不能包含空格和其他特殊字符。
- **大小写敏感**：变量名区分大小写，即 `myVariable` 和 `MyVariable` 是两个不同的变量。

- **避免使用 Python 关键字**：不要将 Python 的关键字（如 `if`, `for`, `class` 等）用作变量名。

### 命名规范

不遵守不会报错，但在公司里面会有要求。至少见名知意，不要乱命名

- **变量名、函数名**：小驼峰命名，首字母小写，例如，xxxYyyZzz
- **类名**：大驼峰命名，例如，XxxYyyZzz
- **常量**：蛇形命名法，全部大写，例如，XXX\_YYY\_ZZZ
- **私有成员**：前缀 `_` 表示私有成员。，在类中使用，目前记住就好了

## 列表的概念

列表，类型为 list，可以使用方括号 `[]` 来定义一个列表，将元素放在方括号内，元素之间用逗号隔开。是一个有序存储数据的容器，可以存储多个数据，每个元素都有一个索引位置对应。一般在使用时，都是存储同一类型的数据，在其它语言中一般称为数组。

## 列表的定义

格式：`列表名 = [ 值, 值, 值, ... ]`

## 获取列表的长度

获取列表的长度，即列表中的元素个数，使用`len(列表)`来获取

## 查看列表的类型

`type(列表)`

## 列表的索引

索引为元素在列表中的位置，取值范围为

- 正数，`0<=index<列表长度`，colors 列表的索引范围就是，0<=index<6
- 负数，`-列表长度<=index<0`，colors 列表的索引范围就是，-6<=index<=-1

### 取值

# 元组（Tuple）（掌握）

元组（Tuple）是Python中的一种数据结构，它与列表有一些相似之处，但也有其独特的特点。以下是关于Python元组的详细介绍：

## 元组的定义

元组使用小括号 `()` 来定义，将元素放在小括号内，元素之间用逗号隔开。可以包含不同类型的元素，并且元组一旦创建，其元素个数和内容就不能修改（不可变特性）。

注意：如果元组中只有一个元素，需要在元素后面添加逗号，否则Python会将其视为该元素本身，而不是一个元组。

## 取值

- 通过索引：`变量名 = 元组名 [ 索引 ]`
- `变量名1, 变量名2, ... = 元组名`，要求变量名的数据必须与元组中的数量一致

## 元组的索引和切片

### 元组长度

通过`len(元组名称)`获取元组长度

### 索引

- 正数，`0<=index<列表长度`​
- 负数，`-列表长度<=index<0`​

### 切片

元组也支持切片操作，语法与列表的切片语法相同，即 `tuple[start:stop:step]`，其中：

- `start`：表示切片的起始位置（包含该位置的元素），如果省略则从元组开头开始。
- `stop`：表示切片的结束位置（不包含该位置的元素），如果省略则到元组末尾结束。
- `step`：表示切片的步长，即每次获取元素的间隔，如果省略则步长为 `1`。

## 元组的遍历

可以使用 `for` 循环来遍历元组中的元素，与遍历列表的方式类似。

## 元组的特点及用途

### 不可变特性

元组的主要特点是其不可变，一旦创建，就不能对其元素进行添加、删除、修改等操作。这使得元组在一些场景下非常有用，比如：

- **保护数据完整性**：当你希望某些数据在整个程序执行过程中保持不变时，可以使用元组来存储。例如，存储一些配置信息、数学常数等，确保这些数据不会被意外修改。
- **函数返回多个值**：函数可以返回一个元组来传递多个值。这样在调用函数时，可以一次性接收多个返回值并进行相应的处理。

### 可作为字典的键

由于元组是不可变的，所以它可以作为字典的键使用，而列表因为是可变的，不能作为字典的键。

## 元组与列表的比较

|  |  |  |
| --- | --- | --- |
| 比较项目 | 元组 | 列表 |
| 可变性 | 不可变，元素不能修改 | 可变，元素可以添加、删除、修改 |
| 定义符号 | 小括号 `()` | 方括号 `[]` |
| 内存占用 | 通常比列表占用更少的内存，因为其不可变性质使得Python  不需要为其预留额外的内存空间来支持可能的元素修改操作 | 相对元组可能占用更多内存，因为需要考虑元素的可变性 |
| 用途 | 适用于存储固定的数据组合，保护数据完整性，作为字典键等 | 适用于需要频繁修改数据的场景，如数据的动态添加、删除、排序等 |

元组在Python中是一种很有用的数据结构，在不同的编程场景下可以根据具体需求选择使用元组或列表。

# 字典（Dictionary）（掌握）

## 字典的定义

字典是一种无序的、可变的数据结构，用于存储键值对（key-value pairs）。字典使用花括号 `{}` 来定义，每个键值对之间用逗号隔开，键和值之间用冒号 `:` 分隔。

在这个例子中，`'name'`、`'age'` 和 `'city'` 是键（keys），`'Alice'`、`30` 和 `'New York'` 是对应的值（values）。

## 字典的添加和修改

# 函数(超级超级重点)

## 函数的定义（基础）

在 Python 中，使用 `def` 关键字来定义一个函数。函数是一段可重复使用的代码块，它接受输入参数（也可以没有参数），执行特定的操作(就是你的业务功能)，并可以返回一个结果（也可以不返回任何结果）。格式：

- `def 函数名(形参列表):` ：不明确返回值的函数，一般不需要指定，形参列表可以没有，多个参数之间使用逗号分隔

- 函数中的代码，需要缩进，称为函数体

- `def 函数名(形参列表) -> 返回值类型1 | 返回值类型2:` ：指定了返回值类型，支持多个类型可以使用`|`分隔，指定了也没有什么特别要求，更加明确，方便别人使用理解

在上述示例中，`def greet():` 定义了一个名为 `greet` 的函数，函数体内部的 `print("Hello, World!")` 语句就是该函数要执行的操作。函数的文档注释（使用三引号 `""" """`）用于描述函数的功能等信息，这有助于提高代码的可读性和可维护性。

## 函数的调用（基础）

定义好函数后，需要通过调用函数来执行函数体内部的代码。

当执行 `greet()` 这一行代码时，就会执行 `greet` 函数内部的 `print("Hello, World!")` 语句，在控制台输出 `Hello, World!`。

## 函数的参数（基础）

函数可以接受参数，参数是在函数定义时指定的变量，用于接收调用函数时传入的值，这样可以使函数更加灵活，能够根据不同的输入执行不同的操作。

### 位置参数

位置参数是最常见的参数类型，调用函数时传入的参数值会按照定义的顺序依次赋给函数中的参数。

在上述示例中，`add_numbers` 函数定义了两个位置参数 `a` 和 `b`，当调用该函数时，传入的 `3` 和 `5` 会分别赋给 `a` 和 `b`，然后函数内部计算 `a + b` 的值并返回。

> 使用位置参数，需要一一对对，这个有点麻烦，所以 python 也提供关键字参数

### 关键字参数

关键字参数是通过参数名来指定参数值的方式，调用函数时可以不按照参数定义的顺序传入参数，只要指定了正确的参数名和对应的值即可。

在上述示例中，`greet_pPeson` 函数定义了两个参数 `name` 和 `greeting`，调用函数时通过 `greet_person(greeting="Good morning", name="Alice")` 这种方式，使用关键字参数传入了值，即使顺序与函数定义时不同，也能正确地将值赋给对应的参数，函数内部会打印出 `Good morning, Alice!`。

#### 强制使用关键字参数

在函数定义中，可以在需要强制使用关键字参数的参数前面放置一个 `*`，这样在调用函数时，位于 `*` 之后的参数就必须通过关键字参数的形式来传递。

### 默认参数

默认参数是在函数定义时就为参数指定了一个默认值，调用函数时如果没有传入该参数的值，就会使用默认值。

### 可变参数

在Python中，可变参数允许函数在定义时接受不确定数量的参数。这使得函数更加灵活，可以处理不同数量的输入值。Python中有两种常见的可变参数形式：`*args` 和 `**kwargs`。以下是关于它们的详细介绍及示例：

#### ​`*args`（非关键字可变参数）

- `*args` 用于在函数定义中接收任意数量的位置参数（非关键字参数）。这些参数会被收集到一个**元组（tuple）**中，在函数内部可以像处理普通元组一样处理它们。

- `*args` 还可以和其他普通位置参数一起使用，此时普通位置参数需要在 `*args` 之前定义，并且在调用函数时需要先传入普通位置参数的值。

#### ​`**kwargs`（关键字可变参数）

`**kwargs` 用于在函数定义中接收任意数量的关键字参数。这些参数会被收集到一个**字典（dictionary）**中，在函数内部可以像处理普通字典一样处理它们。

在上述示例中：

- 定义了函数 `print_kwargs`，它使用了 `**kwargs` 来接收可变数量的关键字参数。
- 当调用 `print_kwargs(name='Alice', age=30)` 时，`name='Alice'` 和 `age=30` 这两个关键字参数会被收集到一个字典中，其中 `name` 和 `age` 是键，`Alice` 和 `30` 是对应的值。然后在函数内部通过遍历字典的键值对并打印出每个键值关系。
- 同样，调用 `print_kwargs(city='New York', country='USA')` 会将 `city='New York'` 和 `country='USA'` 收集到字典中并打印。
- 调用 `print_kwargs()` 时，由于没有传入任何关键字参数，`kwargs` 就会是一个空字典，函数内部的循环不会执行任何操作。

`**kwargs` 也可以和其他普通参数（包括 `*args`）一起使用，此时普通参数需要在 `**kwargs` 之前定义，并且在调用函数时需要先传入普通参数的值。

在这个示例中：

- 函数 `print_mixed_kwargs` 有一个普通位置参数 `a`，`*args` 用于接收可变数量的其他位置参数，`**kwargs` 用于接收可变数量的关键字参数。
- 当调用 `print_mixed_kwargs(10, 20, 30, name='Alice', age=30)` 时，`10` 会被赋给 `a`，`20` 和 `30` 会被收集到 `args` 元组中，`name='Alice'` 和 `age=30` 会被收集到 `kwargs` 字典中。在函数内部先打印出 `a` 的值，然后遍历打印 `args` 元组中的元素，最后遍历打印 `kwargs` 字典中的键值对。

总结来说，`*args` 和 `**kwargs` 是Python中非常有用的特性，它们使得函数能够更加灵活地处理不同数量和类型的输入参数，提高了函数的通用性和可复用性。

## 装饰器的概念

装饰器是Python中的一个强大特性，它本质上是一个函数，用于在不修改被装饰函数源代码和调用方式的情况下，对函数的功能进行扩展或修改。可以把装饰器想象成一个包装器，它将被装饰的函数包裹起来，在函数执行前后添加一些额外的逻辑。

## 装饰器的应用场景

- **日志记录**：可以在函数执行前后记录相关信息，如函数名称、执行时间、输入参数和输出结果等，方便调试和监控程序运行情况。
- **权限验证**：在函数执行前验证用户是否具有执行该函数的权限，若没有权限则可以采取相应的措施，如抛出异常或返回错误提示。

## 构造方法（掌握）

构造方法（Constructor）是面向对象编程中用于初始化对象的方法。在 Python 中，构造方法主要通过 `__init__` 方法实现。

- 所谓初始化，就是在创建对象之前，需要做的事情，一般是对属性进行赋值
- Python 默认会给每个类提供一个无参的构造方法，除非程序员写了自定义的构造方法

## 类属性和实例属性（掌握）

- **类属性**：定义在类中但在方法之外的变量，属于类本身，所有实例共享同一个类属性。

- **定义**：类属性是属于类本身的属性，被所有类的实例所共享。所有实例都可以访问和修改这个属性，并且对类属性的修改会影响到所有实例。
- **创建方式**：在类的内部，方法外部定义。
- **访问方式**：可以通过类名直接访问和修改，也可以通过实例对象访问，但通过实例对象修改时要注意，可能会创建一个同名的实例属性而不是修改类属性。

- **实例属性**：定义在 `__init__` 方法或其他方法中的变量，属于特定的实例，每个实例都有自己的副本。

- **定义**：实例属性是属于类的每个实例的属性。每个实例都有自己独立的一组实例属性，它们的值可以在不同实例之间有所不同。
- **创建方式**：通常在类的 `__init__` 方法中初始化，也可以在类的其他方法或类外部为实例动态添加。
- **访问方式**：通过实例对象来访问和修改。

- **私有属性**：在 Python 中，私有变量是通过命名约定而非严格的访问限制来实现的。所以 Python 没有真正的私有变量

### 实例方法

实例方法是类中最常见的方法类型。它的第一个参数通常是 `self`，这个参数代表类的实例对象本身。通过 `self` 可以访问和修改实例的属性以及调用其他实例方法。

### 静态方法

- **定义**：静态方法是属于类的方法，但它与类的实例和类本身没有直接关联，它不依赖于类属性和实例属性，也不会对类属性和实例属性进行修改。
- **创建方式**：使用 `@staticmethod` 装饰器定义。
- **访问方式**：可以通过类名或实例对象调用。

# 异常处理

Python 中的异常处理是一种机制，用于在程序执行过程中遇到错误时控制程序的行为。通过使用异常处理，你可以编写更健壮、更易于维护的代码。Python 提供了 `try`、`except`、`else` 和 `finally` 语句来处理异常。

## 基本结构

### try-except 语句

这是最基本的异常处理结构。`try` 块包含可能引发异常的代码，而 `except` 块用来处理这些异常。

#### try-except-else 语句

如果 `try` 块没有抛出异常，则执行 `else` 块中的代码。

#### try-except-finally 语句

无论是否发生异常，`finally` 块中的代码都会被执行。这通常用于清理工作，如关闭文件或网络连接。有了 with 这个关键字，一般不怎么使用 finally。

### 总结

- **try**：包含可能引发异常的代码。
- **except**：处理特定类型的异常。
- **else**：如果没有异常发生则执行。
- **finally**：无论是否发生异常都执行。
- **raise**：手动抛出异常。
- **自定义异常**：创建自己的异常类。
- **with 语句**：简化资源管理，确保资源被正确释放。
