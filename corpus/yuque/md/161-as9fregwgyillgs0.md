### **1. 线程（Thread）**

- **定义**：线程是操作系统调度的最小单位，属于同一进程的多个线程共享内存空间。
- **Python 模块**：`threading` 模块。
- **特点**：

- **共享内存**：线程共享进程的内存（变量、文件句柄等），通信简单但需注意线程安全。
- **GIL 限制**：Python 的全局解释器锁（GIL）导致同一时刻仅一个线程能执行 Python 字节码，**多线程在 CPU 密集型任务中无法并行**。
- **轻量级**：创建和切换开销小。

- **适用场景**：

- **I/O 密集型任务**：如网络请求、文件读写（等待 I/O 时释放 GIL）。
- **异步协作**：需快速响应但不需要并行计算的场景。

### **2. 进程（Process）**

了解即可

- **定义**：进程是操作系统资源分配的最小单位，不同进程有独立的内存空间。每个程序在运行后都会有一个进程
- **Python 模块**：`multiprocessing` 模块。
- **特点**：

- **独立内存**：进程间不共享内存，需通过 IPC（管道、队列等）通信。
- **绕过 GIL**：每个进程有独立的 Python 解释器和 GIL，可真正并行执行 CPU 密集型任务。
- **重量级**：创建和切换开销较大。

- **适用场景**：

- **CPU 密集型任务**：如数学计算、图像处理。
- **需要利用多核 CPU** 的并行计算。

### **3. 关键对比**

|  |  |  |
| --- | --- | --- |
| **特性** | **线程** | **进程** |
| **内存共享** | 共享进程内存 | 独立内存，需 IPC 通信 |
| **GIL 影响** | 受 GIL 限制（伪并发） | 无 GIL 限制（真并行） |
| **创建开销** | 小 | 大 |
| **数据通信复杂度** | 低（直接共享变量） | 高（需队列/管道） |
| **适用场景** | I/O 密集型任务 | CPU 密集型任务 |
| **容错性** | 一个线程崩溃可能导致进程终止 | 一个进程崩溃不影响其他进程 |

### **5. 小结**

- **用线程**：处理 I/O 阻塞型任务（如 HTTP 请求、文件操作）。
- **用进程**：需并行执行 CPU 密集型计算（如数值模拟、数据处理）。
- **混合使用**：如多进程处理计算 + 多线程处理每个进程内的 I/O。

### **6. 进阶内容**

- **线程安全**：共享数据时需用锁（`threading.Lock`）。
- **进程间通信**：使用 `multiprocessing.Queue` 或 `Pipe`。
- **避免全局变量**：进程间无法共享全局状态。
