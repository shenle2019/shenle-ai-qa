# 概述

## 简介

Git 是一个开源的分布式版本控制系统，用于敏捷高效地处理任何或小或大的项目。

## 核心概念

- **工作区（Workspace）**：就是你在电脑里能看到的目录。
- **暂存区（Index/Stage）**：一般存放在 ".git/index" 中，它像个缓存区域，临时保存你的改动。
- **本地仓库（Repository）**：工作区有一个隐藏目录 ".git"，这个不算工作区，而是 Git 的版本库。
- **远程仓库（Remote）**：托管代码的服务器，可以简单地认为是你项目组中的一台电脑用于远程数据交换。

- `git reset .`：取消所有的文件
