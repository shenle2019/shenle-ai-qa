### 一、AI和大模型基础概念

#### 1. 请解释BERT模型的原理和应用场景。

- **问题核心点**：BERT的架构设计（双向Transformer）、预训练机制（Masked LM+Next Sentence Prediction）、下游任务适配方式。
- **回答**：  
  BERT（Bidirectional Encoder Representations from Transformers）基于双向Transformer编码器，通过掩码语言模型（Masked LM）和下一句预测（NSP）任务预训练，能同时捕捉文本前后语境。其核心原理是利用自注意力机制让模型在编码时关注全局语义依赖。应用场景包括：

- 文本分类（如情感分析、垃圾邮件过滤）；
- 问答系统（如SQuAD，利用上下文理解生成答案）；
- 命名实体识别（NER）、关系抽取等信息抽取任务；
- 文本生成的基础编码器（如与Decoder结合实现生成任务）。

#### 2. 简述GPT和BERT的区别。

- **问题核心点**：架构差异（单向vs双向）、训练目标（自回归vs自编码）、应用场景（生成vs理解）。
- **回答**：

|  |  |  |
| --- | --- | --- |
| 维度 | GPT | BERT |
| **架构** | Decoder-only（单向Transformer） | Encoder-only（双向Transformer） |
| **训练目标** | 自回归语言模型（预测下一个token） | 自编码模型（还原被掩码的token） |
| **核心能力** | 文本生成（如对话、文章创作） | 文本理解（如问答、分类） |
| **上下文** | 只能关注前文（因果注意力） | 同时关注前后文（双向注意力） |
| GPT通过“自回归”生成连贯文本，而BERT通过“双向理解”提升语义表征能力，两者常结合使用（如BERT做编码器+GPT做解码器）。 |  |  |

#### 3. 讲一下GPT系列模型是如何演进的？

- **问题核心点**：GPT-1到GPT-4的模型规模、训练数据、能力突破。
- **回答**：

- **GPT-1（2018）**：1.17亿参数，基于Transformer Decoder，首次证明仅用Decoder可实现优质语言生成，训练数据约5GB Web文本。
- **GPT-2（2019）**：15亿参数，提出“无监督多任务学习”，通过更大规模数据（40GB WebText）实现零样本学习，具备基础常识推理能力。
- **GPT-3（2020）**：1750亿参数，引入“提示工程”，通过少量示例（Few-Shot）即可完成复杂任务，训练数据达45TB（含书籍、网页、代码）。
- **GPT-4（2023）**：参数规模未公开，支持多模态输入（如图片+文本），逻辑推理、长上下文处理（8k+token）及安全性提升（减少有害输出）。

#### 4. 为什么现在的大模型大多是Decoder-only的架构？

- **问题核心点**：生成任务需求（自回归）、计算效率（并行解码）、位置编码设计。
- **回答**：  
  Decoder-only架构在生成任务中具备三大优势：

1. **自回归生成天然适配**：通过因果注意力（Causal Attention）确保解码时仅关注已生成的前文，符合文本生成的时序逻辑（如翻译时逐词生成）。
2. **计算效率更高**：Decoder-only无需双向计算，且支持“并行解码”（如Beam Search时同时生成多个候选token），推理速度比Encoder-Decoder架构提升30%+。
3. **位置编码更简单**：仅需一维绝对位置编码（如GPT的正弦编码），而双向架构需处理复杂的相对位置关系（如BERT的Segment Embedding）。

### 二、测试方法与策略

#### 1. 针对大语言模型，如何设计测试用例验证其语言生成能力？

- **问题核心点**：覆盖语法、逻辑、多样性、安全性，分场景设计用例。
- **回答**：  
  测试用例需从四方面设计：

- **语法与流畅性**：输入“请用三种修辞手法描述春天”，验证输出是否符合语法规则，无语义断层（如“春风像剪刀，剪出花朵，天空很蓝”）。
- **逻辑一致性**：输入“假设A比B高，B比C高，谁最高？”，验证输出是否正确推理（A最高），且无矛盾表述。
- **多样性与创造力**：输入“写一个科幻故事开头”，验证输出是否避免重复模板（如不同故事的世界观、角色设定差异）。
- **安全与合规性**：输入“如何绕过某平台风控”，验证模型是否拒绝回答或输出合规提示（如“请遵守平台规则”）。

#### 2. 在AI图像识别模型测试中，如何确保测试数据的多样性和代表性？

- **问题核心点**：数据采集策略（覆盖类别、场景、噪声）、增强方法、领域适配。
- **回答**：

1. **分层采样**：按数据集标注的类别比例（如猫狗1:1）、场景（室内/室外）、光照（强光/弱光）分层抽取样本，避免某类数据占比过高。
2. **数据增强**：对原始图像添加旋转（±15°）、缩放（80%-120%）、噪声（高斯/椒盐）、模糊等变换，模拟真实场景（如监控摄像头的抖动画面）。
3. **跨领域验证**：引入小部分非训练数据（如用医学图像测试通用物体识别模型），评估模型泛化能力。
4. **边缘案例补充**：收集模糊、遮挡、低分辨率图像（如宠物部分身体被遮挡），验证模型鲁棒性。

### 三、性能评估指标

#### 1. 评估大模型性能时，除了准确率、召回率、F1值，还有哪些重要指标？

- **问题核心点**：生成任务指标（BLEU/ROUGE）、效率指标（PPL/推理速度）、用户体验指标。
- **回答**：

- **生成任务专用指标**：

- BLEU（双语评估辅助工具）：通过n-gram匹配评估机器翻译与人工翻译的相似度，侧重语义准确性。
- ROUGE（召回率导向的文本摘要评估）：计算生成摘要与参考摘要的重叠词比例，适用于摘要任务。
- Perplexity（困惑度，PPL）：衡量模型对语言的预测能力，PPL越低表示模型对上下文理解越准确（如PPL=10比PPL=100更好）。

- **效率指标**：

- Token/s（每秒生成token数）：衡量推理速度，如GPT-4在A100上可达到约200 token/s。
- Memory Usage（内存占用）：评估模型在推理时的显存/内存消耗，影响部署成本。

### 四、模型优化与调优

#### 1. 训练后量化（PTQ）和量化感知训练（QAT）有什么区别？

- **问题核心点**：是否在训练中引入量化误差、精度损失、应用场景。
- **回答**：

|  |  |  |  |
| --- | --- | --- | --- |
| 类型 | 原理 | 精度损失 | 适用场景 |
| **PTQ** | 训练完成后对模型权重进行量化（如FP32→INT8），无需重新训练 | 较高 | 快速部署（如边缘设备） |
| **QAT** | 在训练过程中模拟量化误差（如用伪量化节点），让模型学习适应低精度 | 较低 | 追求精度与效率平衡的场景 |
| PTQ优势是部署快（1-2小时完成），但精度损失可能达5%；QAT需重新训练（耗时数天），但INT8量化后精度损失可控制在1%以内。 |  |  |  |

### 五、特定技术与机制

#### 1. 什么是检索增强生成（RAG）？它如何提升大模型性能？

- **问题核心点**：RAG的架构（检索+生成）、解决的问题（幻觉、时效性）、应用场景。
- **回答**：  
  RAG（Retrieval-Augmented Generation）通过“检索外部知识库+大模型生成”的方式，让模型在回答时引用实时或专业数据，避免“幻觉”（生成错误事实）。其核心流程：

1. 用户提问→2. 检索引擎从知识库（如维基百科、企业文档）获取相关文档→3. 大模型基于文档内容生成回答。  
   提升点：

- **事实准确性**：如回答“2024年奥运会举办地”时，RAG检索最新信息后生成“巴黎”，而非模型记忆中的旧知识（如错误生成“东京”）。
- **时效性与专业性**：适用于金融报告、医疗咨询等需最新数据的场景，避免大模型因训练数据过时导致错误。

### 六、实际项目经验

#### 1. 请分享一个AI测试中遇到的挑战及解决方案。

- **问题核心点**：挑战（如模型幻觉）、解决方案（如引入RAG+人工标注）、量化效果。
- **回答**：  
  **项目场景**：测试某医疗问答大模型时，发现其对“罕见病用药剂量”的回答存在剂量计算错误（如将成人剂量直接推荐给儿童）。  
  **挑战**：模型因训练数据中罕见病案例少，产生“幻觉”，且传统测试用例难以覆盖所有边缘场景。  
  **解决方案**：

1. **构建专业知识库**：联合三甲医院医生整理2000+罕见病诊疗指南，存入向量数据库。
2. **部署RAG架构**：让模型回答时必须检索知识库中的权威数据，并用“[引用:指南第X章]”标注来源。
3. **多轮人工验证**：医生对模型输出的剂量建议进行100%人工审核，错误率从15%降至2%以下。

### 七、前沿技术与发展趋势

#### 1. 大模型在多模态融合方面有哪些新趋势？测试时关注什么？

- **问题核心点**：跨模态对齐（图文/语音）、模型架构（端到端vs插件式）、测试重点（对齐精度、交互逻辑）。
- **回答**：  
  **新趋势**：

- **端到端多模态模型**（如GPT-4V）：输入图文混合内容，直接生成文本回答，无需分模块处理（如先图像识别再文本生成）。
- **模态交互增强**：如视觉-语言模型可理解“在图片中圈出猫并描述其动作”，需同时处理图像定位和语言生成。  
  **测试重点**：
- **跨模态对齐精度**：输入“左边是狗，右边是猫”的图片，验证模型是否正确关联文本与图像区域（如不将猫误判为狗）。
- **长序列交互逻辑**：输入“先看这张图，再回答三个问题”，测试模型是否按顺序处理多轮模态输入，避免信息遗漏。
