# **三. WebUI自动化功能说明**

该部分主要是讲解整个WEB自动化的操作流程，基于这个功能模块，我们主要分为模块有：

项目管理、浏览器集群管理、关键字方法管理、项目页面管理、页面元素管理、WEB用例信息管理、WEB测试计划管理等几个模块。

### **3.1 项目管理模块**

在该模块主要是维护需要做WEB自动化的项目，主要的功能有：新增、编辑、删除、数据库配置。

图3 项目管理列表页面

#### **3.1.1 功能说明：**

● **新增项目：**输入对应的项目名称和项目描述即可添加对应的项目。

● **编辑项目：**可结合你的需要修改对应的项目名称和项目描述的值。

● **删除项目：**可直接删除对应的项目数据。

● **数据库配置：**可维护当前项目对应的数据库信息。具体功能请参考：**数据库配置模块**

### **3.2 数据库配置模块**

### **3.4 关键字维护功能**

可以维护对应的关键字数据，在该功能主要2个核心，其一：可以维护**核心执行器**自带的一些维护后的固有的方法，其二：可以自定义关键字同时注意要生成对应的文件（**注意：关键字方法名、方法体中的类名、方法名都必须保持一致**）。

#### **3.4.1 功能说明：**

● **筛选功能：**可通过关键字描述和操作类型，点击【查询】按钮能进行对应的模糊查询。

● **新增关键字方法：**在该功能可以维护对应的关键字信息，可以结合功能说明中的2个核心去进行操作。

字段说明：

1. **是否启动：**是否应用该关键字

2. **所属操作类型**：选择对应的操作类型，方便根据关键字进行筛选，同时这个位置是数据库当中的默认值。

3. **关键字名称：**方便自身去查看对应的方法是用来做什么的。中文即可.

4. **关键字方法名：**要么直接输入对应的**核心执行器**自带的一些方法名，比如：**open\_browser、quit\_browser**；或者自定义的方法名，注意：如果是自定义的方法名，**一定要填写对应的方法体**，其中**关键字方法名、方法体中的类名、方法名都必须保持一致 ，****然后点击【生成关键字文件】按钮。****同时不能重名。**

5. **关键字描述：**描述该关键字需要填写的参数，如下：

### **3.5 页面管理**

管理对应项目的页面，同时可以结合页面名称和所属项目进行搜索功能及编辑、删除功能。如下图 页面管理功能。

图 页面管理功能

#### **3.5.1 功能说明：**

● **筛选功能：**输入原页面名称和项目名称，点击【查询】按钮能进行对应的模糊查询。

● **新增页面：**选择**所属项目**（必填，**项目管理维护的数据**）、输入页面名称（必填）、页面描述可以添加对应的页面数据。

● **编辑项目：**可结合你的需要修改对应所属项目（必填）、输入页面名称（必填）、页面描述的值。

● **删除项目：**可直接删除对应的页面数据。

### **3.6 页面元素管理**

管理对应项目对应的页面下的某个元素。可结合所属项目、所属页面、元素名称、定位方式、表达式、元素描述字段进行添加数据。支持查询、新增元素、编辑、删除功能。图 元素管理页面。

图 元素管理页面

#### **3.6.1 功能说明：**

● **筛选功能：**可通过元素名称、所属项目、所属页面，点击【查询】按钮能进行对应的模糊查询。

● **新增元素：**可通过输入对应的所属项目、所属页面、元素名称、定位方式、表达式、元素描述进行筛选。其中所属项目、所属页面为其它模块维护的数据。定位方式默认数据为：id,name,link text,partial link text,tag Name,class name,xpath,css selector

● **编辑功能：**可结合你的需要修改对应数据的值。

● **删除功能：**可直接删除对应的元素数据。

### **3.7 WEB用例信息管理**

结合之前维护的基础信息编写测试用例,并且可以进行调试执行.支持查询、新增、编辑、删除功能。图 用例信息列表页面。

图 用例信息列表页面

#### **3.7.1 功能说明：**

● **筛选功能：**可通过用例名称、所属项目、点击【查询】按钮能进行对应的模糊查询。

● **新增用例：**可通过填写对应的用例信息进行添加，并且进行调试执行。

● **编辑功能：**可结合你的需要修改对应数据的值。

● **删除功能：**可直接删除对应的用例数据。

### **3.8 WEB测试计划管理**

结合WEB用例信息管理进行增加测试计划管理，添加多个测试用例信息。能够进行用例计划的维护，参数化、运行环境的配置、以及结合Jenkins进行执行等功能。图 测试计划列表页面。

图 测试计划列表页面。

#### **3.8.1 功能说明：**

● **筛选功能：**可通过集合名称、所属项目、点击【查询】按钮能进行对应的模糊查询。

● **新增用例：**可通过选择对应的用例信息进行添加，并且进行执行，需要的话，也可以结合Jenkins进行定时执行。

● **编辑功能：**可结合你的需要修改对应数据的值。

● **删除功能：**可直接删除对应的用例数据。

● **执行测试计划：****维护的测试计划可以进行执行操作**

● **执行记录：可以查看当前测试计划的执行记录**

● **复制计划：可以快速的复制当前的测试计划**

#### **3.8.2 新增计划-功能说明**

如下图添加的是一个新增的计划

**注意事项：**

1. 可以在【用例维护】当中选择对应的用例，显示所有的数据。

**2.****基于添加的用例，我们可以去添加对应的测试数据，从而事项数据驱动。**

**注意：添加驱动的数据之后记得一定要记得保存噢。同时记得一定要维护执行的顺序。**

3. 然后选择对应的【运行环境配置】，选择对应的浏览器，可以添加当前测试集合需要用到的全局变量。

4. 如果需要Jenkins的话，结合Jenkins环境配置进行配置。

**最后保存之后就可以在列表页面，进行执行，查看结果了。**
