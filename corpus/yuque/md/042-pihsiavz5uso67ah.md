# 产品概述

## 产品简介

### 核心定位

Claude 是由 Anthropic 公司研发的新一代大语言模型，与 ChatGPT 相比，其核心优势在于超大上下文窗口（支持最长100k tokens，可直接处理完整文档、代码库）、更强的代码生成与调试能力、更高的安全性和合规性，无需复杂配置即可实现精准的自然语言交互和专业任务处理，广泛应用于开发者日常编码、长文本分析、多轮对话等场景。

### 核心能力

Claude 具备四大核心能力，覆盖日常使用和专业开发场景，其中代码相关能力（俗称 Claude Code）是其亮点：

- 自然语言交互：支持流畅的多轮对话，可解答各类疑问、生成文案、翻译文本、总结归纳，理解人类意图的准确率高；
- 代码能力（Claude Code）：可生成、调试、解释多种编程语言代码（Python、Node.js、SQL、Java 等），支持代码优化、注释生成、错误定位，适配开发者日常编码需求；
- 长文本处理：依托超大上下文窗口，可直接导入 PDF、Word 文本、代码文件等，进行全文分析、总结、提炼关键信息，无需拆分文本；
- 多模态能力（Claude 3 系列）：支持图片识别与分析，可解读图片中的文字、图表、代码片段，结合文本生成对应结果，适配多场景使用需求。

## 核心概念区分

很多使用者会混淆 Claude 相关核心概念，此处明确区分，避免使用踩坑，尤其适配开发者场景：

### Claude API

Claude API 是 Anthropic 官方提供的底层接口，是所有 Claude 相关工具、SDK 的基础。开发者可通过发送 HTTP 请求调用该接口，实现与 Claude 模型的交互，但直接调用需手动处理请求头、身份验证、参数格式化等底层逻辑，操作繁琐，适合高级开发者自定义需求。

### Claude SDK

Claude SDK（软件开发工具包）是 Anthropic 官方基于 Claude API 封装的标准化开发工具，支持 Python、Node.js 等主流编程语言。其核心作用是简化 API 调用流程，封装了身份验证、请求发送、响应解析等底层逻辑，开发者无需从零编写复杂代码，导入 SDK 即可快速调用 Claude 模型，是日常开发中最常用的方式。

### Claude Code

Claude Code 并非 Anthropic 官方定义的标准化术语，而是行业和用户对 Claude 模型「代码相关能力」的统称。其核心是 Claude 模型具备的代码生成、调试、解释、优化等功能，可通过 SDK、API 或官方界面调用，是开发者使用 Claude 的核心需求之一。
