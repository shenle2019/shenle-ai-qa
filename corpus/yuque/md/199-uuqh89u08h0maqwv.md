# 概述

## 简介

Apache JMeter 是一款功能强大且广受欢迎的开源性能测试工具，由 Apache 软件基金会开发并维护，完全基于 Java 语言编写。

### 主要用途

- **负载测试**：能够模拟大量用户同时对各类应用系统发起请求，借此来评估系统在不同负载水平下的性能表现，比如确定系统可以承受的最大并发用户数量、分析系统响应时间随着负载增加如何变化等，确保系统在实际运行中面对预期的高流量场景时依然能够稳定、高效地运转。
- **性能测试**：可精确测量应用程序多个方面的性能指标，像服务器的吞吐量（单位时间内处理的请求数量）、响应时间（从客户端发起请求到接收到服务器响应所花费的时长）、资源利用率（如 CPU、内存等硬件资源的使用情况）等，帮助开发人员和运维团队发现潜在的性能瓶颈，以便针对性地进行优化。

### 适用范围

- **Web 应用测试**：起初，JMeter 主要侧重于对 Web 应用程序开展测试工作，能够模拟浏览器行为向 Web 服务器发送 HTTP（s）请求，涵盖了常见的 GET、POST 等请求类型，并且支持处理 Cookies、HTTP 头信息、SSL 加密等诸多和 Web 相关的特性，以此验证 Web 应用在不同条件下的功能完整性和性能状况。
- **拓展测试领域**：随着不断发展，其应用范围已经拓展到了更广泛的测试场景。它可以用于测试数据库系统，通过配置 JDBC 连接来模拟对数据库的各种操作，检验数据库的性能和稳定性；也能够对 FTP 服务器进行测试，模拟文件传输的操作来查看服务器的承载能力；还适用于消息中间件（如 JMS）、SOAP / RESTful Web 服务等多种类型的应用或服务的性能及功能测试。

## 表格查看结果

参数

- Sample #：每个请求的序号
- Start Time：每个请求开始时间。（时：分：秒.毫秒）
- Thread Name：每个线程的名称（线程序号-第N次循环次数）
- Label：每个请求的自定义名称（无修改时默认显示请求类型，如Http，FTP等请求）
- Sample Time(ms)：每个请求的响应时间。（单位：毫秒）
- Status：请求状态，如果为勾则表示成功，如果为叉表示失败
- Bytes：响应的字节数，请求的字节数
- Sent Bytes：发送的字节数
- Latency：延迟的时间，等待时长。（单位：毫秒）
- Connect Time(ms)：连接服务器的时间。（单位：毫秒）

## 正则表达式提取器

Json 提取器，一般要求接口返回的结果是 Json 格式的数据。而正则表达式提取器，没有限制，可以提取任何数据中的内容

要检查的响应字段，根据要取出的值在请求中的哪个部分来处理

1. 主体：响应体，不包含响应头；最常用
2. body(unescaped)：响应体，替换了所有HTML转义符；
3. body as a Document：从不同类型的文件中提取文本；影响性能
4. 信息头：响应头
5. Requeste Headers：请求头
6. URL：URL
7. 响应代码：响应码(Response code)
8. 响应信息：响应信息(Response message)

- 变量=截取的全部字段，彼此字段间以空格相隔，如上图第一行。
- 变量\_g：应代表截取的变量个数？
- 变量\_g0: 根据正则表达式匹配到的（截取前的）完整字段。
- 变量\_g1:截取到的第一个字段，使用时${变量名\_g1}。

### vars 和 props 区别

|  |  |  |
| --- | --- | --- |
| **特性** | **vars（JMeterVariables）** | **props（JMeterProperties）** |
| **作用域** | 线程级（每个线程独立） | 全局级（所有线程共享） |
| **生命周期** | 线程执行期间有效，线程结束后销毁 | 测试计划启动到结束全程有效 |
| **数据类型** | 仅支持字符串 | 支持任意 Java 对象（但通常存储字符串） |
| **读写权限** | 线程内可读写，其他线程不可见 | 所有线程可读可写 |
| **性能影响** | 读写速度快（线程内操作） | 读写速度较慢（涉及全局锁） |
| **典型用途** | 存储线程私有数据（如用户会话、临时计算结果） | 存储全局配置（如服务器地址、最大重试次数） |

## JSR223 PostProcessor

**JSR223 PostProcessor 是 JMeter（一款性能测试工具）中的后置处理器元件**，主要用于在 sampler（如 HTTP 请求）执行后，通过脚本语言（如 Groovy、Python、JavaScript 等）对响应结果进行处理、提取数据或执行其他自定义操作。它基于 **JSR223 规范**（Java Specification Request 223，即脚本引擎 API）实现，允许用户通过编写脚本灵活扩展 JMeter 的功能。

CSV数据文件设置参数解析：

1. 名称：自己命名即可。
2. 注释：自己命名即可，可以为空。
3. 文件名：选择文件的路径，点击浏览选择文件的绝对路径即可。如果在linux服务器上，最好选择相对路径，把CSV文件和脚本放在同一个目录下。
4. 文件编码：默认为ANSI（ASCII码的拓展），可以选择为UTF-8
5. 变量名称：CSV文件中的数值存放在变量中，供后续引用。变量可以多个，用英文逗号隔开，变量分别读取CSV文件中的列。
6. 忽略首行：如果CSV文件中设置了首行的字段，比如“用户名”等，这些字段不是要使用的数据，那么就可以选择忽略首行。
7. 分隔符：默认是逗号，比如txt文件中，设置多个值，用英文逗号隔开。
8. 是否允许带引号：默认False
9. 遇到文件结束符再次循环？：默认Ture，代表继续从文件的第一行循环读取数据，False表示不再循环。
10. 遇到文件结束符停止线程？：默认False，Ture表示停止线程。
11. 线程共享模式：默认【所有现场】

### 汇总报告

汇总报告与聚合报告类似，但是相比聚合报告，汇总报告使用更少的内存。

**属性描述**

- **名称** ：显示的此取样器的描述性名称，可自定义
- **文件名** ：要保存或/读取的测试结果文件名，包含路径
- **Label** ：执行样品的标签，如HTTP请求的名称，事务控制器名称
- **样本**： 执行的，具有相同标签的样本数量。需要注意，多个样本同名的将被统计在一起，所以在编写脚本时样品命名应该唯一，除非你希望这么做。
- **平均值**：一组样本的平均响应时间
- **最小值**： 一组样本中最短的响应时间
- **最大值**：一组样本中最长的响应时间
- **异常%**： 执行失败的请求占一组样本的百分比
- **吞吐量**： 以每秒/分钟/小时的请求数衡量。以使显示的速率至少为1.0。代表完成的请求数/秒/分钟/小时，通常可以反应服务器的事务处理能力
- **接收/sec**： 数据接收速率，反应获取数据的网络使用情况
- **发送/sec**： 数据发送速率，反应发送数据的网络使用情况
- **平均字节数**： 样本响应数据的平均大小，以字节为单位

在测试资源允许的情况下，可保留此监听器执行测试，但依然更推荐使用CLI模式保存测试结果后再使用聚合报告进行查看分析以降低对性能的影响。

## JDBC Connection Configuration

**JDBC 连接配置**（JDBC Connection Configuration）是 JMeter 中的一个配置元件，用于管理与数据库的连接。通过配置 JDBC 连接，JMeter 可以在测试过程中与数据库进行交互，执行 SQL 查询或其他[数据库操作](https://so.csdn.net/so/search?q=%E6%95%B0%E6%8D%AE%E5%BA%93%E6%93%8D%E4%BD%9C&spm=1001.2101.3001.7020)。这对于需要从数据库中读取数据或向数据库写入数据的性能测试场景非常有用。

### 添加 JDBC 连接配置

右键点击测试计划或线程组，选择 **添加** -> **配置元件** -> **JDBC Connection Configuration**。

### **配置项详解**

- **基本配置**

|  |  |
| --- | --- |
| **配置项** | **作用** |
| **Variable Name** | 数据库连接池的变量名，供后续 JDBC Request 引用（如 `dbpool`） |
| **Database URL** | JDBC 连接 URL，格式示例： MySQL: `jdbc:mysql://host:port/dbname` Oracle: `jdbc:oracle:thin:@host:port:SID` |
| **JDBC Driver Class** | 数据库驱动类名： MySQL: `com.mysql.cj.jdbc.Driver` Oracle: `oracle.jdbc.driver.OracleDriver` |
| **Username** | 数据库用户名 |
| **Password** | 数据库密码 |

- **高级配置**

|  |  |
| --- | --- |
| **配置项** | **作用** |
| **Connection Pool** | 设置连接池参数： - **Initial Size**: 初始连接数 - **Max Active**: 最大活跃连接数 - **Max Wait**: 连接超时时间（毫秒） |
| **Validation Query** | 连接验证 SQL（如 `SELECT 1`），用于检查连接是否有效 |
| **Transaction Isolation** | 事务隔离级别（如 `TRANSACTION_READ_COMMITTED`） |
| **Auto Commit** | 是否自动提交事务（勾选为自动提交） |
| **KeepAlive** | 是否保持长连接 |

- **高级选项（Advanced）**

|  |  |
| --- | --- |
| **配置项** | **作用** |
| **Cache Prepared Statements** | 是否缓存预编译语句（提高性能） |
| **Prepared Statements Cache Size** | 预编译语句缓存大小 |
| **Connection Properties** | 额外连接属性（如 `useSSL=false`），格式：`key1=value1;key2=value2` |
