# 一、概述

本消息通知模块支持钉钉、飞书、微信三种平台的配置，可维护对应的数据。在测试计划中选择机器人并启用后，当测试执行完毕，系统将自动发送对应的消息。

# 二、配置步骤

## 2.1 钉钉配置

### | 第一步：获取机器人信息

- 登录钉钉，进入需要配置机器人的群聊。

- 点击群聊右上角的“群设置”，选择“机器人”。

- 点击“添加机器人”，选择“自定义（通过Webhook接入自定义服务）”。

- 按照提示完成机器人的创建，记录下Webhook地址。

**| 如图所示：**

### | 第二步：在系统中配置钉钉机器人

- 打开本系统的消息通知模块配置界面。

- 选择“钉钉”选项卡。

- 输入获取到的Webhook地址。

- 可根据需要设置其他相关参数，如消息格式、通知范围等。

- 点击“保存”完成钉钉机器人的配置。

## 2.2 飞书配置

在该模块主要是维护飞书机器人的相关消息，主要的功能有：新增、编辑、删除、查询。如下核心介绍一下新增功能。

### | 第一步：获取机器人信息

- 登录飞书，进入需要配置机器人的群聊。

- 点击群聊右上角的“群设置”，选择“机器人”。

- 点击“添加机器人”，选择合适的机器人类型（如自定义机器人）。

- 按照提示完成机器人的创建，**记录下Webhook地址和密钥（如果有**）。

**| 如图所示：**

### | 第二步：在系统中配置飞书机器人

- 打开本系统的消息通知模块配置界面。

- 选择“飞书”选项卡。

- 输入获取到的Webhook地址和密钥（如果有）。

- 可根据需要设置其他相关参数，如消息格式，也可以点击消息体模板。

- 点击“保存”完成飞书机器人的配置。

**| 如图所示：**

## 2.3 微信配置

在该模块主要是维护微信机器人的相关消息，主要的功能有：新增、编辑、删除、查询。如下核心介绍一下新增功能。

### | 第一步：获取机器人信息

- 登录企业微信，进入需要配置机器人的群聊。

- 点击群聊右上角的“···”，选择“群机器人”。

- 点击“添加机器人”，按照提示完成机器人的创建，记录下Webhook地址。

**| 如图所示：**

### | 第二步：在系统中配置微信机器人

- 打开本系统的消息通知模块配置界面。

- 选择“微信配置”菜单。

- 填写机器人别名，输入获取到的**Webhook地址**。

- 可根据需要设置其他相关参数，如消息格式，也可以点击消息体模板。

- 点击“保存”完成微信机器人的配置。

# 三、在测试计划中使用机器人

### 入口：

- 接口自动化 -- API 测试计划管理

- WEB自动化 -- WEB测试计划管理

- APP自动化 -- APP测试计划管理

进入到如上页面——编辑页面，点击【机器人通知配置】进行添加，选择需要使用的机器人（钉钉、飞书或微信）。勾选已选择的机器人前面的启用框。确认设置无误后，保存测试计划。

# 四、消息发送验证

### 入口：

- 接口自动化 -- API 测试计划管理 --- 列表--- 执行测试计划

- WEB自动化 -- WEB测试计划管理--- 列表--- 执行测试计划

- APP自动化 -- APP测试计划管理--- 列表--- 执行测试计划

> 当测试执行完毕后，检查对应的钉钉、飞书或微信群聊中是否收到消息通知。

- 如果收到消息，说明配置和使用正常。

- 如果未收到消息，检查以下内容：

- 机器人的Webhook地址是否正确。

- 机器人是否在对应的群聊中正常工作。

- 系统中机器人的配置参数是否正确。
