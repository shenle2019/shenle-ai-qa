## 【第一部分】表结构操作

### 题目1：创建用户表（user）

**答案：**

**解析：**

- `CREATE TABLE` 用于创建新表
- 使用反引号`` ` ` ` ``包裹表名和字段名，避免与SQL关键字冲突
- 字段定义包括字段名、数据类型和长度（如适用）
- `INT` 表示整数类型，`VARCHAR(20)` 表示最大长度为20的可变字符串，`DATE` 表示日期类型

### 题目2：向用户表中追加字段email

**答案：**

**解析：**

- `ALTER TABLE` 用于修改表结构
- `ADD` 关键字用于添加新字段
- 默认情况下，新字段会添加到表的末尾

### 题目3：向用户表最前面添加字段status

**答案：**

**解析：**

- `FIRST` 关键字指定新字段添加到表的第一列
- 注意：MySQL支持此语法，但并非所有数据库都支持 `FIRST` 关键字

### 题目4：向用户表password字段后面添加sage

**答案：**

**解析：**

- `AFTER` 关键字指定新字段添加在指定字段之后
- 可以精确控制新字段在表中的位置

### 题目5：修改sage的名称为age

**答案：**

**解析：**

- `CHANGE` 关键字用于修改字段名称（和/或数据类型）
- 语法：`CHANGE 旧字段名 新字段名 新数据类型`
- 即使数据类型不变也需要重新指定

### 题目6：修改password字段的长度为50

**答案：**

**解析：**

- `MODIFY` 关键字用于修改字段的数据类型（或长度）
- 注意：`MODIFY` 不能修改字段名，只能修改数据类型和约束

### 题目7：修改status到email之后的位置

**答案：**

**解析：**

- 使用 `MODIFY` 结合 `AFTER` 可以移动字段位置
- 需要重新指定字段的数据类型

### 题目8：删除字段status

**答案：**

**解析：**

- `DROP` 关键字用于删除字段
- 删除字段会永久删除该字段及其所有数据

### 题目9：修改表的名称为userinfo

**答案：**

**解析：**

- `RENAME TO` 用于修改表名
- 也可以使用 `RENAME TABLE` 语句

### 题目10：清空数据库表

**答案：**

**解析：**

- `TRUNCATE TABLE` 清空表中所有数据
- 与 `DELETE FROM` 的区别：

- `TRUNCATE` 是DDL操作，更快，不能回滚，重置自增ID
- `DELETE` 是DML操作，逐行删除，可以加WHERE条件，可以回滚

### 题目11：销毁数据库表user

**答案：**

**解析：**

- `DROP TABLE` 永久删除整个表结构和数据
- 如果表不存在，会报错（可以使用 `IF EXISTS` 避免错误）

## 【第二部分】数据查询与操作

### 题目1：找出所有姓张的学生，并按年龄从小到大排列

**答案：**

**解析：**

- `LIKE` 用于模式匹配，`%` 匹配任意字符序列
- `'张%'` 表示以"张"开头的字符串
- `ORDER BY` 用于排序，`ASC` 表示升序（从小到大）
- 也可以省略 `ASC`，默认就是升序

### 题目2：取出计算机科考成绩不及格的学生

**答案：**

**解析：**

- 使用 `JOIN`（内连接）连接两个表，基于共同的 `Code` 字段
- 为表指定别名（X和Y）简化代码
- `WHERE` 条件包含两个部分：科目为"计算机"且分数小于60
- 注意：数据表中是"计算机"不是"计算机科"

### 题目3：在TableX表中增加一条学生记录

**答案：**

**解析：**

- `INSERT INTO` 用于插入新记录
- 必须指定表名和字段名
- `VALUES` 后面是对应字段的值
- 字段顺序必须与值顺序一致

### 题目4：根据主键进行更新李五的年龄记录

**答案：**

**解析：**

- `UPDATE` 用于修改已有记录
- `SET` 指定要修改的字段和新值
- `WHERE` 条件应基于主键（Code）而不是姓名，因为主键唯一标识记录
- 根据数据表，李五的Code是97004

### 题目5：删除TableX中没有考试成绩的学生记录

**答案：**

**解析：**

- 使用子查询找出TableY中所有有成绩的学生Code
- `NOT IN` 表示不在这个集合中
- 删除TableX中Code不在TableY中的记录
- 更安全的方式：先备份或使用事务

### 题目6：取出每一个科目成绩最高的学生记录

**答案：**

**解析：**

- 使用相关子查询：对于每一行，找出同科目的最高分
- 外层查询只选择分数等于该科目最高分的记录
- 连接TableX获取学生姓名
- 如果多个学生在同一科目获得相同最高分，都会显示
- 另一种方法：使用窗口函数 `ROW_NUMBER()` 或 `RANK()`

## 【第三部分】车辆信息操作

### 题目1：新车登记错误，修改浙A12A26的车辆颜色为黄色

**答案：**

**解析：**

- 使用 `UPDATE` 语句修改记录
- `SET` 指定要修改的字段和值
- `WHERE` 条件指定要修改的记录（车牌号为浙A12A26）
- 注意：原车颜色是black

### 题目2：计算小型汽车的平均车速

**答案：**

**解析：**

- `AVG()` 聚合函数计算平均值
- 使用 `JOIN` 连接车辆信息表和违法表
- `Car_Type` = 2 表示小型汽车（根据题目描述）
- `AS` 为计算结果指定别名
- 注意：违法表中有车速记录，但车辆信息表中没有
