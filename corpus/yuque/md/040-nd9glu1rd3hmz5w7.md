## 一、无子命令的命令（独立命令）

以下命令直接执行特定功能，不包含子命令：

|  |  |
| --- | --- |
| **命令** | **功能说明** |
| **setup** | 初始化本地配置和代理工作区 |
| **configure** | 交互式设置向导，用于配置凭据、频道、网关和代理默认值 |
| **onboard** | 网关、工作区和技能的交互式入驻向导 |
| **completion** | 生成 shell 补全脚本 |
| **reset** | 重置本地配置和状态（保留已安装的 CLI） |
| **uninstall** | 卸载网关服务和本地数据（CLI 本身保留） |
| **agent** | 通过网关运行单次代理轮次 |
| **dashboard** | 使用当前令牌打开控制 UI（图形界面） |
| **tui** | 打开连接到网关的终端 UI（文本界面） |
| **docs** | 搜索在线 OpenClaw 文档 |
| **doctor** | 健康检查以及针对网关和频道的快速修复 |
| **logs** | 通过 RPC 跟踪网关文件日志 |
| **health** | 从运行中的网关获取健康状态 |
| **status** | 显示频道健康状况和最近的会话接收者 |
| **qr** | 生成 iOS 配对二维码和设置代码 |
| **help** | 显示命令的帮助信息 |

## 三、全局选项

|  |  |
| --- | --- |
| **选项** | **说明** |
| **--dev** | 开发模式：在 `~/.openclaw-dev`  下隔离状态，默认网关端口 19001，并偏移衍生端口 |
| **-h, --help** | 显示命令帮助 |
| **--log-level** | 全局日志级别覆盖（silent|fatal|error|warn|info|debug|trace） |
| **--no-color** | 禁用 ANSI 颜色 |
| **--profile** | 使用命名配置文件（在 `~/.openclaw-<name>`  下隔离状态和配置） |
| **-V, --version** | 输出版本号 |
