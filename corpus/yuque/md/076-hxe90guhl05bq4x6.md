## 一、项目概述

### 1.1 网站基本信息

**网站名称：** 读书屋**域名：** novel.hctestedu.com**创建时间：** 2019年**网站定位：** 集创作、阅读、作品加工、IP运营为一体的中文小说阅读综合平台

### 1.2 系统架构特点

读书屋是一个多端（PC、WAP）阅读、功能完善的原创文学CMS系统，由多个子系统构成：

- **前台门户系统**：面向读者的内容展示与阅读平台
- **作家后台管理系统**：为作者提供作品创作、管理功能
- **平台后台管理系统**：支持平台运营、内容审核、用户管理
- **爬虫管理系统**：实现内容自动抓取与更新

### 1.3 核心功能特性

✅ **多端支持**：PC端、移动端自适应，提供流畅阅读体验✅ **会员体系**：支持充值、订阅模式，灵活的付费阅读机制✅ **内容管理**：新书自动入库，老书自动更新章节✅ **运营工具**：新闻发布、实时统计报表、排行榜管理✅ **作者服务**：作家专区、作品统计、收益结算、创作指导✅ **用户体验**：书架管理、阅读记录、评论互动、搜索推荐

## 二、功能模块详细需求

### 2.1 用户模块

#### 2.1.1 用户注册/登录

**功能描述：**支持游客注册成为会员，提供邮箱/手机号验证码登录、密码登录方式。

**界面元素：**

- 登录入口：顶部导航栏"登录/注册"按钮
- 登录表单：账号输入框、密码输入框、验证码、登录按钮
- 注册表单：用户名、密码、确认密码、邮箱/手机号、验证码

**业务规则：**

- 用户名唯一性校验
- 密码强度要求（8-20位，包含字母+数字）
- 验证码60秒刷新机制
- 登录失败5次锁定账号10分钟

#### 2.1.2 用户中心

**功能描述：**用户登录后进入个人中心，可查看阅读历史、书架内容、充值记录、订阅信息等。

**界面布局：**

**功能项：**

- **最近阅读**：展示最近阅读的书籍及阅读进度
- **我的书架**：收藏的书籍列表，支持分类管理
- **充值记录**：充值金额、时间、订单详情
- **订阅管理**：已订阅书籍的章节更新提醒

### 2.2 内容展示模块

#### 2.2.1 首页布局

**功能描述：****网站首页采用经典小说网站布局，顶部导航栏+轮播图+内容分栏结构。**

**页面结构：**

**数据展示：**

- **本周强推**：每周更新的5本推荐书籍
- **热门推荐**：基于阅读量的热门书籍
- **精品推荐**：平台精选高质量作品
- **新书榜单**：最新上架的书籍列表

#### 2.2.2 书籍详情页

**功能描述：**点击书籍封面或书名进入详情页，展示书籍基本信息、作者信息、章节列表、读者评论等。

**页面模块：**

**交互功能：**

- 章节点击进入阅读页
- 收藏书籍到书架
- 发表评论（需登录）
- 分享书籍链接

### 2.3 阅读模块

#### 2.3.1 阅读页面

**功能描述：**用户点击章节后进入阅读页面，提供舒适的阅读体验和便捷的导航功能。

**界面设计：**

**功能特性：**

- **自动保存阅读进度**：关闭后可继续阅读
- **字体调节**：支持小/中/大三种字号
- **背景切换**：白色/护眼黄/夜间模式
- **章节导航**：上一章/下一章/目录
- **自动滚动**：可选自动翻页功能
- **批注功能**：支持对内容做个人笔记

#### 2.3.2 阅读记录

**功能描述：**系统自动记录用户的阅读历史，包括书籍名称、章节、阅读时间、阅读进度等信息。

**存储内容：**

- 书ID和书名
- 章节ID和章节名
- 阅读时间戳
- 阅读进度（百分比）
- 阅读时长（分钟）

### 2.4 书架模块

#### 2.4.1 书架管理

**功能描述：**用户可将喜欢的书籍加入书架，支持分类管理、批量操作、搜索筛选等功能。

**界面布局：**

**分类管理：**

- **全部**：展示所有收藏书籍
- **收藏**：永久收藏的书籍
- **追更**：正在追更的连载书籍
- **阅读中**：最近阅读的书籍

**操作功能：**

- 添加到书架
- 从书架移除
- 批量管理（多选操作）
- 按作者/类型/时间排序
- 关键词搜索

### 2.5 搜索模块

#### 2.5.1 搜索功能

**功能描述：**提供全站搜索功能，支持按书名、作者、类型关键词搜索，并支持高级筛选。

**搜索界面：**

**搜索维度：**

- **按书名搜索**：精确匹配/模糊匹配
- **按作者搜索**：作者名匹配
- **按类型搜索**：言情、玄幻、都市、穿越等
- **按状态筛选**：连载/完结/精品
- **按字数筛选**：10万以下/10-50万/50万以上

**搜索建议：**

- 实时搜索提示
- 历史搜索记录
- 热门搜索标签

### 2.6 排行榜模块

#### 2.6.1 多维排行榜

**功能描述：**提供多个维度的排行榜，包括点击榜、推荐榜、新书榜、月票榜等，帮助用户发现优质内容。

**排行榜分类：**

**榜单类型：**

- **点击榜**：按阅读量排序
- **推荐榜**：编辑推荐作品
- **新书榜**：最近上架新书
- **月票榜**：用户投票排行
- **收藏榜**：书架收藏数量
- **评论榜**：评论活跃度

**更新规则：**

- 点击榜：实时更新
- 其他榜单：每日更新一次

### 2.7 作者模块

#### 2.7.1 作家专区

**功能描述：**为作者提供创作、管理、数据统计等功能的后台管理系统。

**主要功能：**

- **作品管理**：创建/编辑/删除作品
- **章节管理**：发布/编辑/删除章节
- **数据统计**：阅读量、收藏数、评论数、收益统计
- **创作工具**：在线编辑器、大纲辅助、素材库
- **消息中心**：系统通知、读者反馈

#### 2.7.2 作者申请流程

**功能描述：**游客可申请成为作者，需要提交申请信息并审核通过后获得创作权限。

**申请步骤：**

1. 填写申请表单（用户名、密码、笔名、简介）
2. 通过在线测试（基础创作知识）
3. 平台审核（1-3个工作日）
4. 审核通过后获得作者账号

### 2.8 充值模块

#### 2.8.1 会员充值

**功能描述：**支持用户充值购买VIP会员或订阅书籍，多种套餐选择，安全支付。

**充值界面：**

**会员权益：**

- 月卡：全站书籍30天阅读权
- 季卡：全站书籍90天阅读权+优先更新
- 年卡：全站书籍365天阅读权+专属标识+作者互动

#### 2.8.2 订阅模式

**功能描述：**用户可按章节付费订阅单本书籍，支持按章购买或包月订阅。

**订阅选项：**

- **按章购买**：2-5元/章
- **包月订阅**：30元/月（该书籍无限阅读）
- **终身订阅**：该书籍完结前无限阅读

## 三、非功能需求

### 3.1 性能需求

|  |  |
| --- | --- |
| **指标** | **要求** |
| 页面加载时间 | 首页≤2秒，详情页≤3秒 |
| 并发用户数 | ≥1000人同时在线 |
| 响应时间 | API接口响应≤500ms |
| 搜索响应 | 搜索结果≤1秒返回 |

### 3.2 安全需求

- 用户密码加密存储（MD5+盐值）
- SQL注入防护
- XSS攻击防护
- CSRF攻击防护
- 敏感操作二次验证
- HTTPS全站加密

### 3.3 兼容性需求

- **浏览器兼容**：Chrome、Firefox、Safari、Edge最新版本
- **移动端适配**：iOS 12+、Android 8+自适应布局
- **分辨率支持**：1920×1080至1366×768

### 3.4 SEO优化需求

- 页面TDK标签完整
- 结构化数据标记
- 站点地图生成
- 静态资源CDN加速
- 图片懒加载优化

## 四、数据库设计要点

### 4.1 核心数据表

**用户表 (user)**

- 用户ID、用户名、密码、邮箱、手机号
- 创建时间、最后登录时间、会员等级

**书籍表 (book)**

- 书籍ID、书名、作者、类型、状态
- 封面图片、简介、字数、章节数
- 创建时间、更新时间、点击量

**章节表 (chapter)**

- 章节ID、书籍ID、章节名、章节号
- 内容、字数、创建时间、更新时间

**阅读记录表 (read\_record)**

- 记录ID、用户ID、书籍ID、章节ID
- 阅读时间、阅读进度、阅读时长

**书架表 (bookshelf)**

- 书架ID、用户ID、书籍ID
- 添加时间、分类、状态

**评论表 (comment)**

- 评论ID、用户ID、书籍ID、章节ID
- 评论内容、评分、创建时间

### 4.2 数据索引优化

- 书籍表：书名索引、作者索引、类型索引
- 章节表：书籍ID索引、章节号索引
- 阅读记录：用户ID+书籍ID联合索引
- 评论表：书籍ID索引、创建时间索引

## 五、接口设计

### 5.1 后台API接口

**用户相关接口：**

- POST /api/user/register - 用户注册
- POST /api/user/login - 用户登录
- GET /api/user/profile - 获取个人信息
- PUT /api/user/profile - 更新个人信息

**书籍相关接口：**

- GET /api/book/list - 获取书籍列表（支持分页、筛选）
- GET /api/book/detail/{id} - 获取书籍详情
- POST /api/book/create - 创建书籍（作者）
- PUT /api/book/update/{id} - 更新书籍信息

**章节相关接口：**

- GET /api/chapter/list/{bookId} - 获取章节列表
- GET /api/chapter/detail/{id} - 获取章节内容
- POST /api/chapter/create - 创建章节（作者）
- PUT /api/chapter/update/{id} - 更新章节内容

**阅读相关接口：**

- POST /api/read/record - 记录阅读进度
- GET /api/read/history - 获取阅读历史
- POST /api/read/bookshelf - 添加到书架
- DELETE /api/read/bookshelf/{id} - 从书架移除

### 5.2 第三方接口

- **支付接口**：支付宝、微信支付
- **短信接口**：验证码发送
- **CDN接口**：图片上传、加速分发
- **搜索接口**：ElasticSearch集成

## 八、风险与应对

### 8.1 技术风险

**风险：** 高并发下数据库性能瓶颈**应对：** 读写分离、Redis缓存、SQL优化

**风险：** 存储成本增长**应对：** 图片压缩、CDN加速、定期归档

### 8.2 运营风险

**风险：** 内容版权纠纷**应对：** 严格审核机制、版权声明、投诉处理流程

**风险：** 用户留存低**应对：** 个性化推荐、阅读提醒、社区互动
