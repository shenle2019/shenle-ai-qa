## 简介

AnythingLLM 是一款高效、可定制、开源且适用于企业的文档聊天机器人解决方案，被称为与任何事物聊天的私人 ChatGPT

官网地址：<https://anythingllm.com/desktop>

- **功能特点**

- **支持多种模型和数据库**：可选择和使用商用的现成 LLM 或流行的开源 LLM 及向量数据库，如兼容 llama.cpp 的开源模型、OpenAI、Azure OpenAI、Anthropic ClaudeV2 等，还支持 LanceDB、AstraDB、Pinecone 等多种向量数据库。
- **多用户管理和权限设置**：支持多用户实例，可轻松进行团队协作，能对不同用户设置访问权限，确保数据安全和隐私。
- **多种文档类型支持**：支持 PDF、TXT、DOCX 等多种文档类型，可将各种文档、资源或内容转换成 LLM 能在聊天中使用的上下文。
- **两种聊天模式**：有 “对话” 和 “查询” 模式。“对话” 模式保留之前的问题和修正，“查询” 模式针对文档进行简单问答。
- **其他功能**：通过简单 UI 管理向量数据库中的文档，聊天中的引用可链接到原始文档来源和文本，具有完整的开发者 API，便于自定义集成，还具备高效的成本节约措施，在处理大文档时比其他解决方案节省 90% 的成本。

- **技术架构**：单体仓库包含三个主要部分。“collector” 是 Python 工具，能将在线资源或本地文档快速转换成 LLM 可用格式；“frontend” 是 viteJS + React 前端，用于创建和管理 LLM 可用的内容；此外，还包含一个收集匿名使用信息的遥测功能，遥测提供商是 PostHog。
- **应用场景**

- **个人助理**：用户可通过聊天与个人文档交互以检索信息。
- **企业知识管理**：可在企业内构建智能问答系统，提高工作效率。
- **教育和研究**：利用 AI 与学术材料互动，辅助学习和研究。
