# 01 · Python 入门与第一个 AI 生成程序

> 本章目标：把「装环境 → 写第一行代码 → 用变量存数据 → 用输入输出做交互 → 让 AI 帮我写代码」走通一遍。学完能独立写出「问姓名、问三门成绩、算总分平均分」的小程序。

## 1. 三个东西的关系

新手卡住的地方通常不是语法，而是「我写的代码到底跑在哪」。

| 角色 | 是什么 | 本章用 |
| --- | --- | --- |
| 解释器 | 真正执行 `.py` 的程序 | CPython 3.11+ |
| 编辑器 / IDE | 写代码的地方，本身不执行 | VS Code 或 PyCharm |
| 终端 | 敲命令、看输出、装依赖 | PowerShell |

关系是：**终端调用解释器 → 解释器读 `.py` → 结果打印回终端**。IDE 只是帮你编辑，并顺手替你在终端敲了那条命令。

「代码不运行」时先查三件事：文件存了吗、终端当前目录对不对、用的是哪个解释器（`python -V`）。

## 2. 第一个程序

```python
print("Hello, AI 测试")
```

保存为 `hello.py`，在同目录执行：

```powershell
python hello.py
```

`print()` 是函数，括号里是参数。多个值用逗号分隔，输出自动补空格：

```python
name = "李明"
print("学生姓名：", name)   # 学生姓名： 李明
```

## 3. 变量：有名字的盒子

`name = "李明"` 做两件事：在内存里放一个值，把名字贴上去。

```python
name = "李明"      # str
chinese = 85       # int
average = 87.5     # float
passed = True      # bool
```

- `int`：成绩、数量、年龄
- `float`：平均分、身高、价格
- `bool`：只有 `True` / `False`
- `str`：文本，必须加引号

查类型用 `type()`：`print(type(average))` → `<class 'float'>`。

::: warning 最容易踩的坑
`"85"` 和 `85` 不是一个东西。`input()` 拿到的**永远是字符串**，要算数必须先 `int()` 或 `float()`。
:::

## 4. 输入与输出

```python
name = input("请输入姓名：")
chinese = int(input("请输入语文成绩："))
print(f"{name} 的语文成绩是 {chinese}")
```

`input()` 的参数是提示语，返回值是 `str`。`f"..."` 里花括号可以直接写变量或表达式。

## 5. 命名与缩进

命名（违反不报错，但会坑人）：字母/数字/下划线、不能数字开头、区分大小写、不能撞关键字；变量与函数用 `snake_case`。

缩进（违反直接报错）：Python 用缩进表示代码块，同块必须对齐，推荐 4 空格，不要混 Tab。

```python
# 错：IndentationError
if True:
print("hi")

# 对
if True:
    print("hi")
```

实验里的 `labs/ch01-hello-ai/errors/` 就是这两个反例的最小复现，可以直接跑一遍看报错。

## 6. 用 AI 写代码：四步法

课程反复强调的闭环，本质是把「描述需求」当成手艺：

1. **明确需求**：输入是什么、输出是什么、异常怎么处理
2. **让 AI 生成**：一次只要一个函数或一个脚本，别要一整个系统
3. **运行验证**：拿真实输入跑，看输出对不对，别只看代码像不像
4. **迭代提示词**：补约束（类型、边界、格式），而不是重写整段

可用的提示词骨架：

```
用 Python 写一个脚本：
- 输入：从命令行依次读取姓名、语文、数学、英语成绩
- 处理：成绩转成数字，算总分和平均分
- 输出：四行文本：姓名、总分、平均分、是否及格（平均分 >= 60）
- 约束：输入非法（非数字、超出 0-100）时提示并重新输入
- 只用标准库
```

第 3 步最容易被跳过，但它是唯一能证伪的一步。

## 7. 常见错误对照

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `SyntaxError: invalid syntax` | 少括号、少引号、中文标点 | 看行号，逐个符号对 |
| `IndentationError` | 缩进不一致 | 统一 4 空格，别混 Tab |
| `NameError: name 'x' is not defined` | 变量没赋值或拼错 | 检查赋值与大小写 |
| `TypeError: can only concatenate str` | 字符串和数字直接相加 | 先 `int()` / `str()` |
| `ValueError: invalid literal for int()` | `int("abc")` | 先判断输入是否合法 |
